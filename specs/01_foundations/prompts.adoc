== 1. Data model

=== 1.1 Spec

[source,text]
----
Write a spec specs/01_foundations/01-data-model.spec.adoc for the data model of the
meeting-room booking app (office hoteling): Building, Floor, Room, Desk, Amenity, Booking
(who/what/when/status), composition building→floor→rooms+desks, M2M Room↔Amenity, status
enum. Explicitly write down what is out of scope (screens, roles, slot check) and the
acceptance criteria. Delete rules must be expressible in the entity model, because Studio
regenerates the changelog from the entities: no hand-written database-only cascades.
----

Result: `01-data-model.spec.adoc` with open questions; no code yet.

NOTE: The last sentence was added after the original session. Without it the agent
put a database-level cascade on the `ROOM_AMENITY_LINK` foreign key. Nothing in the
entities expresses that rule, so the next Studio diff reverted it.

=== 1.2 Spec review and implementation

[source,text]
----
Approved. Answers: 1 - OffsetDateTime is fine; 2 - not now; 3 - ok; 4 - three statuses
are enough. Implement the spec.
----

Result: entities, enum and message keys; Gate 1 evidence; a list of what the Studio
changelog must contain. The agent stops there and doesn't write the changelog itself.

== 3. Slot-conflict service

=== 3.1 Spec

[source,text]
----
Write a spec specs/01_foundations/03-slot-conflict-service.spec.adoc for the booking check
service. Rules: (1) endTime is after startTime; (2) exactly one of room/desk is filled;
(3) for the same place there is no other booking with status != CANCELLED whose time
overlaps with [startTime, endTime). The logic - in a @Service with DataManager, no UI code.
The call - on saving a Booking, reject with a clear message. Write down what is out of
scope and the criteria.
----

=== 3.2 Decisions and implementation

[source,text]
----
1 - as suggested, 2 - as suggested. Implement (the app is stopped).
----

Result: the service, a saving listener (every save path), the booking form's
`ValidationEvent` (friendly dialog), message keys, 13 integration tests.

NOTE: If Gate 2 returns raw message keys instead of texts, look for a stale
`.jmix/conf/` (IDE hot deploy copies resources there and they override the classpath).
Compare it with `src`, then remove it.
